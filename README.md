# Downloader-mini

## How it works
1. Downloads file from URL
2. Splits into small chunks (default 50MB)
3. Pushes chunks to GitHub

## How Others Can Use This
1. **Fork this repository**
2. Go to **Actions** tab in YOUR fork
3. Click **"Enable workflows"** if prompted
4. Select **"Download, Split & Push to Repository"** workflow
5. Click **"Run workflow"** and enter the file URL

## Reassemble
- just use reassemble.bat

1. I can't download this url in iran (https://github.com/glotlabs/gdrive/releases/download/3.9.1/gdrive_windows-x64.zip)
